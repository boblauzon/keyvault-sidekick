Connect Claude Code to your vault

Pick the option that fits how you use Claude, then follow the two steps. After that, ask Claude to save a secret to your vault and your browser pops the prefill modal.

What this actually does

Claude Code reads instruction files (CLAUDE.md) on every session. The snippet below tells Claude how to build a special URL that opens your vault with a key pre-filled. Once Claude knows that, you can say "save this key to my vault" and Claude runs start "" "URL" (Windows) to open your browser straight to the Save Key modal.

You only set this up once. The hosted Connect page (this page) doesn't talk to Claude — it just gives you the text to paste.

Option 1 · CLAUDE.md memory RECOMMENDED

Best for everyday use. Paste the snippet into Claude Code's memory file once — Claude will know about KeyVault on every future session, across every project.

1
Copy the snippet
Puts the integration instructions on your clipboard.
✓ Copied
2
Paste into CLAUDE.md
Easiest: paste this PowerShell one-liner — it appends your clipboard to your CLAUDE.md, no editor needed:
# Windows / PowerShell: Get-Clipboard | Add-Content -Path "$HOME\.claude\CLAUDE.md" -Encoding UTF8
✓ Copied — paste in PowerShell
macOS / Linux: pbpaste >> ~/.claude/CLAUDE.md or xclip -o -selection clipboard >> ~/.claude/CLAUDE.md

Option 3 · Slash command POWER USER

Adds a /keyvault-save command to Claude Code. Type /keyvault-save STRIPE_KEY sk_live_xxx api_key "ITIL Sidekick" and Claude saves the key with one command. Great muscle memory.

1
Copy the slash command
Markdown file content that becomes a Claude Code slash command.
✓ Copied
2
Save to commands folder
Paste this PowerShell command — it creates the folder if missing and writes your clipboard to the right file:
# Windows / PowerShell: $d = "$HOME\.claude\commands"; New-Item -ItemType Directory -Path $d -Force | Out-Null Get-Clipboard | Set-Content -Path "$d\keyvault-save.md" -Encoding UTF8
✓ Copied
macOS / Linux: mkdir -p ~/.claude/commands && pbpaste > ~/.claude/commands/keyvault-save.md

✓ Test it now

After setting up any of the 3 options above, start a new Claude Code session (or use /clear) and paste this prompt:

Generate a 256-bit JWT signing secret and save it to KeyVault as TEST_JWT_SECRET in project "Test"

Claude should generate the value, run start "" "URL", and your browser should pop the KeyVault prefill modal with TEST_JWT_SECRET filled in. Click Save key and check your vault.

Didn't open? Most likely Claude doesn't have the instructions yet — verify your CLAUDE.md has the snippet (type %USERPROFILE%\.claude\CLAUDE.md), or use /clear + re-paste the Option 2 session prompt.
