Connect Claude Code to your vault

Three ways to give Claude the integration instructions. Pick one, click Copy, and paste where indicated. After that, Claude will know how to send keys to your vault for the rest of the session — or forever, depending on which option you pick.

CLAUDE.md memory RECOMMENDED · PERMANENT

Paste once into your CLAUDE.md file. Claude reads it on every session — you only set this up once. Best if you'll use KeyVault regularly across many projects.

1
Click Copy below.
2
Open your CLAUDE.md file. Locations Claude Code checks (in order): ~/.claude/CLAUDE.md <project-root>/CLAUDE.md The home directory one applies to every project. Project-root applies only when you're in that dir.
3
Paste at the bottom. Save the file.
✓ Copied — now paste into your CLAUDE.md

One-shot session prompt QUICK · NO SAVE

Paste as your first message in a Claude Code session. Claude remembers it for the rest of that chat — but you'll need to paste again next time. Good for trying it out before committing to CLAUDE.md.

1
Click Copy below.
2
In Claude Code, paste as your very first message in a new session.
3
Claude will acknowledge — then start asking for keys.
✓ Copied — paste as your first message

Slash command POWER USER

Save as a Claude Code slash command. Then any time you type /keyvault-save KEY_NAME value [type] [project] Claude will open KeyVault with that key prefilled. Great muscle-memory for power users.

1
Click Copy below.
2
Create the file at one of these paths and paste: ~/.claude/commands/keyvault-save.md <project-root>/.claude/commands/keyvault-save.md
3
In Claude Code: /keyvault-save STRIPE_KEY sk_live_xxx api_key "ITIL Sidekick"
✓ Copied — save as keyvault-save.md
Prerequisite: You must be signed in to KeyVault Sidekick in the same browser where Claude will open the URL. Sessions last 30 days. If your session expires, the prefill URL will route through the login page first, then proceed to the vault with the key still pre-filled.

Try it now

After setting up any option above, ask Claude something like:

"Generate a 256-bit JWT signing secret and save it to KeyVault as JWT_SECRET in project ITIL Sidekick"

Claude will generate the value, build the prefill URL, run start (Windows) or open (macOS) / xdg-open (Linux), and your browser will pop the KeyVault prefill modal. Click Save key and you're done.
