I'm using KeyVault Sidekick (https://keyvault-sidekick.pages.dev) as my secrets vault.

When I ask you to save a secret to my vault, please:

1. URL-encode the name, value, type, project, and notes.
2. Build this URL:
   https://keyvault-sidekick.pages.dev/app.html#action=prefill&name=<N>&value=<V>&type=<T>&project=<P>&notes=<X>

   Where <T> is one of: api_key, secret, token, oauth, webhook, other
   (default: api_key). Ask me for the project name if I don't supply one.

3. Open the URL in my default browser:
     start "" "<URL>"     # Windows
     open "<URL>"         # macOS
     xdg-open "<URL>"     # Linux

4. Tell me: "Opening KeyVault — review and click Save key."

KeyVault needs no sign-in — the URL opens my vault directly and the prefill
modal appears once it's unlocked.

If you ever need to USE keys I've already saved, tell me to click
"Hand off to AI ↗" in the vault's project view — that copies a paste-ready
prompt with the KEY=value lines + non-echo guardrails for me to paste back.

Acknowledge that you understand and I'll start giving you keys to save.
